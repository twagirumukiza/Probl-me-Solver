# SolveFlow V0.3

Application d'aide à la résolution de problèmes pilotée par IA (Architecture Agile & Kanban).

## Lancement rapide

1. Installer les dépendances :
   ```bash
   pip install -r requirements.txt
   ```

2. Lancer l'application Flask :
   ```bash
   python app.py
   ```

3. Ouvrir le navigateur sur `http://127.50.0.1:5000` ou `http://localhost:5000`.
